# Live Stream · 直播互动项目框架

由**公共直播框架 + 独立玩法项目**组成。公共框架处理桌面启动、直播数据接入和直播小窗，各项目分别维护自己的前端页面、规则和素材。内置头像打印示例与独立二维互动模板，可通过项目清单扩展新玩法。

**抖音直播伴侣负责采集画面与声音并开播推流**。在项目中点击「开始抓取」只会连接直播数据，不会开播。

双击 `start.bat`（`start-all.bat` 为相同入口）打开**项目中心**，选择「头像打印机」或其他项目及其对应页面。不要直接双击 HTML；程序通过本地 HTTP 服务加载模块和素材。

## 项目入口与目录

```text
framework/                  公共项目配置、直播客户端、项目存储与画面输出
  project_registry.py       发现并校验项目配置
  web/                      公共前端运行时和直播小窗
projects/                   各玩法的整合目录
  avatar-printer/           头像打印项目：中英文页面、打印规则、声音和素材
    project.json
    index.html
    index-en.html
  starter/                  可复制开发新玩法的独立互动示例
    project.json
    index.html
index.html                  项目中心，动态展示可用项目与页面
launch.py                   桌面启动及本地服务入口
```

日常使用从项目中心进入；需要直接进入指定玩法时，在项目目录运行：

```powershell
.\start.bat --project avatar-printer
```

查看可用项目：

```powershell
.\.venv\Scripts\python.exe launch.py --list-projects
```

新玩法放入独立的 `projects/<项目id>/` 文件夹，添加自己的 HTML 页面与 `project.json`，刷新项目中心即可发现，无需往头像打印页面继续堆功能。项目设置和小窗通信按项目 id 隔离；切换时回到项目中心选择下一个项目，避免同时打开两个主玩法。桌面切换会收起旧项目小窗，数据桥可继续供新项目使用。新增项目与接口约定见 [开发架构说明](docs/architecture.md)。

## 用抖音直播伴侣开播

首次准备：Windows 10 / 11、Python 3.10 或更新版本、Node.js 22 或更新版本、Microsoft Edge WebView2 Runtime，以及已安装并可登录使用的[抖音直播伴侣](https://streamingtool.douyin.com/)。**首次双击 `setup.bat`**，自动创建本地 `.venv` 并安装 Python 依赖；完成后双击 `start.bat`，在项目中心进入「头像打印机」。也可以在仓库目录手动安装：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

之后按以下顺序操作：

1. 双击 `start.bat`，在项目中心进入「头像打印机」中文页面，先在演示模式确认打印、机械臂和传送带正常。需要英文画面时，选择它的 English 页面。
2. 打开「高级画质设置」，选择输出方向与分辨率。竖屏可先用 `720×1280`，电脑性能允许时用 `1080×1920`；横屏对应 `1280×720` / `1920×1080`。首次建议标准画质、30 FPS，预览流畅后再提高。
3. 点击「弹出画面」，保持 **「直播小窗 · Avatar Printer」** 打开。它镜像主窗口生成的纯 3D 画面；主窗口仍负责打印、渲染和声音，两个窗口都不要关闭或最小化。
4. 在直播伴侣的素材添加入口选择「窗口捕获」（部分版本显示「窗口」），选中 **「直播小窗 · Avatar Printer」**，将素材按比例放到横屏或竖屏画布中。核对预览只有打印画面。官方步骤见[窗口捕获](https://streamingtool.douyin.com/docs/guide_window)和[开播界面](https://streamingtool.douyin.com/docs/guide_live)；入口名称和位置可能随版本变化。
5. 在主打印台点击「开启声音」并调整音量。**直播小窗的视频是静音镜像，声音来自主程序**：在直播伴侣中采集主程序正在使用的扬声器/系统输出设备，确认音量条跳动。若版本支持单独应用音频，选择主打印台进程；不要选择静音小窗。扬声器采集方式见[官方音频说明](https://streamingtool.douyin.com/docs/guide_4beqpl4o)。只保留一条相同声音的采集路径，直播间登录窗口也应静音，避免回声。
6. 预览画面、声音都确认后，由你在直播伴侣中点击开始直播。开播后，在打印台填入**自己的** `live.douyin.com` 房间链接或数字房间号，点击「打开直播间窗口」，完成扫码/验证登录，再点「开始抓取」。看到数据桥已连接后，观众的新互动才会按规则进入打印队列。

若捕获黑屏，先保持小窗打开、在直播伴侣中重新选择窗口；仍无画面，再尝试打印台高级画质设置中的「开启捕获兼容模式并重启」，重启后重新打开小窗并选择采集窗口。兼容模式会增加 CPU 开销，可同时降低画质和帧率。

程序通常使用 `http://127.0.0.1:8080/` 打开项目中心；端口被占用时会自动选择备用端口，桌面主窗口和小窗会使用同一服务。头像打印中文入口为 `/projects/avatar-printer/index.html`，英文入口为 `/projects/avatar-printer/index-en.html`。浏览器调试可运行 `.\.venv\Scripts\python.exe launch.py --server-only`，使用启动时显示的实际地址。

## 内置头像打印示例

演示模式从本地测试头像池中补入任务，逐层打印、出分，再由机械臂转运到前方横向传送带。前方成品与后方打印并行运行；暂停同时冻结打印和流水线，跳过只丢弃当前打印中的物品。开启自动演示会立刻补一张；后续补位间隔可在「打印规则 → 自动演示」中选关闭 / 3 / 5 / 10 / 15 / 30 / 60 / 120 秒，打印中或队列有任务时不重复补入。直播连接后的「无互动时补测试头像」是独立开关，默认关闭，可设置等待 15 / 30 / 60 / 120 秒。

可拖动视角检查模型，「＋保存当前视角」最多保存 10 个命名镜头；随手拖动的视角和上次使用的镜头都会记忆，刷新后自动恢复，「初始视角」可一键回位。高级画质设置提供低 / 标准 / 高 / 超高预设、抗锯齿、目标帧率和流畅优先选项；输出分辨率与内部渲染精细度分别设置，倍率不代表输出尺寸成倍增加。「状态牌」可显示/隐藏画面上的打印状态。直播面板显示连接状态、事件计数和打印进度；打印记录列出昵称、头像、触发方式、大小、分数和时间。

## 真实直播接入（数据桥）

`start.bat` 和 `start-all.bat` 均启动 WebView2 项目中心；进入头像打印项目后使用它的直播控制台。直播间登录窗口需在「直播连接」面板填写房间号后，点击「打开直播间窗口」打开；它使用独立登录配置，首次需要扫码或验证。保持房间在线并登录后再点击「开始抓取」。登录状态保存在本机，不要将浏览器配置目录或头像缓存上传分享。

`start-bridge.bat` 是独立运行数据桥的调试入口，日常桌面开播可直接使用面板控制。切换房间时填写新房间号，重新打开对应直播间窗口并开始抓取，数据桥会跟随房间设置。

项目页面通过公共直播客户端自动发现数据桥端口（默认 `ws://127.0.0.1:8765`，占用时尝试备用端口），连接后显示直播数据状态。头像打印项目的「English / 中文」可切换同目录下的独立中英文页面；英文版 `projects/avatar-printer/index-en.html` 使用该项目的英文语音模块，界面语言切换不会将抖音数据桥变成 TikTok 数据接口。公共直播小窗通过 WebRTC 镜像当前项目主窗口，关闭小窗后主窗口恢复显示现场，不会另起一套打印任务。

「打印规则」可设置评论 / 进场 / 点赞 / 关注 / 礼物是否打印、每次张数、头像大小、礼物优先级、播报和空闲补位。默认评论和礼物打印开启，进场 / 点赞 / 关注打印关闭，礼物答谢和进场欢迎开启。设置立即保存，对新收到的互动生效，已排队任务保持原规则。数据桥连接后自动演示关闭，断开后恢复；直播时是否补测试头像由「无互动时补测试头像」控制。停止抓取会停止本程序启动的数据桥；手动启动的独立桥需在其窗口中关闭。

数据桥通过本机浏览器的调试接口读取直播间页面和协议消息。桌面版使用本程序打开的 WebView2 登录窗口；独立桥还可使用 Chrome / Edge 等调试浏览器。评论、礼物、点赞等事件解析后由本机 WebSocket 转给打印台；不需要在直播伴侣里配置推流地址或数据桥地址。

默认事件映射（可在打印规则中调整，关闭的触发方式不会打印）：

- 评论（含 666、999 等所有发言）→ 1 张小图（发评论也要排队）
- 点赞 → 启用后每赞 1 张小图；协议未提供具体点赞者、只读取到总量增量时，会在累积的活跃观众中轮换归属，此时展示的观众不代表真实点赞者
- 爱心/小心心 → 1 张大图；啤酒 → 2 张大图；棒棒糖 → 3 张大图。开启「礼物优先插队」时立即切换礼物打印，未完成的普通任务保留到礼物之后重新打印，礼物之间按先后顺序处理
- 其他礼物 → 1 张大图；进场 → 播报欢迎不打印

头像优先从直播协议消息提取，并写入本地 `avatar-cache.json` 供后续复用；其次从观众列表、贡献条、进出场记录等页面内容匹配；仍缺失时尝试点击昵称打开资料卡补取。都无法取得时生成彩色首字头像。头像是否可用受直播页面和登录状态影响；挂接前的历史弹幕不补打印，只同步可用头像。评分为娱乐随机分数。登录由用户在直播间窗口完成，程序不代发弹幕、不点赞、不送礼。


## WebView2 桌面版
关闭主窗口会清理本程序启动的直播小窗、直播间登录窗口和数据桥。结束直播请先在直播伴侣中停止直播，再关闭打印程序；关闭打印台不会替你停止直播伴侣的推流。旧版 ServerGuard、BridgeGuard 或手动启动的服务需自行关闭。详细步骤和黑屏、声音排查见打印台顶部的[使用教程](guide.html)。

## 开发与验证

复制 `projects/starter/` 创建新玩法，按 [开发架构说明](docs/architecture.md) 配置项目 id、页面入口与公共运行时。修改公共框架后，可运行：

```powershell
python -m unittest test_project_registry test_launch_ports test_scene_relay
node --test framework-runtime.test.mjs output-stream.test.mjs project-session.test.mjs desktop-client.test.mjs
python -m unittest test_project_http
node test_framework_browser.mjs
```

最后一项使用独立本机服务和无界面浏览器检查项目页面、输出及隔离，不启动真实直播采集。
