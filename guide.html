抖音直播伴侣，5 步接好画面

适用于 Windows 10 / 11。头像打印机生成画面和声音，抖音直播伴侣负责采集并开播推流。「开始抓取」只连接直播互动，不会开播。

使用说明：本框架通过独立项目呈现直播互动。数据桥读取公开互动信息，登录由用户完成，程序不会代发弹幕、送礼或关注。使用与分发条款见 MIT 许可证。
0

环境准备（只做一次）

  • 安装 Python 3（安装时勾选 Add to PATH），然后在项目文件夹中双击 setup.bat，自动创建本地环境并安装依赖；首次安装需要联网
  • 确认已安装 Microsoft Edge WebView2 Runtime，缺失时从微软官网安装
  • 安装 Node.js 22 或更新版本，并准备好已登录、可使用开播功能的抖音直播伴侣
  • 项目文件夹可以放在本机常用位置；启动脚本会优先使用文件夹中的 .venv 环境
1

启动打印台，先看演示

  • 双击 start.bat 打开项目中心，选择「头像打印机」进入打印台；start-all.bat 是相同入口，也可用 start.bat --project avatar-printer 直接打开打印台
  • 暂时不用连接直播间。确认演示头像能逐层打印、出分，再由机械臂送到传送带
  • 需要连续预览时，在「打印规则 → 自动演示」中将补位间隔设为 3 秒或 5 秒；连接真实数据桥后，自动演示会关闭
2

设置输出，打开直播小窗

  • 在「高级画质设置」中选择方向：竖屏 720×1280 / 1080×1920，横屏 1280×720 / 1920×1080
  • 首次可用标准画质、30 FPS。点击「弹出画面」，得到标题为 直播小窗 · Avatar Printer 的纯画面窗口
  • 小窗镜像主窗口的打印画面，主窗口仍负责渲染、打印和声音。主窗口和直播小窗都保持开启，不要最小化；弹出后主窗口收起现场预览属于正常现象
3

直播伴侣采集画面和声音

  • 在直播伴侣的素材添加入口选择「窗口捕获」（部分版本显示「窗口」），选中 直播小窗 · Avatar Printer。将素材按比例放到对应横屏或竖屏画布，确认预览只有打印画面
  • 入口名称、位置可能随版本变化，操作可参考直播伴侣官方窗口捕获指南，无需额外配置推流地址
  • 回到主打印台点击「开启声音」并调整音量。小窗视频是静音镜像，打印音效和播报来自主程序
  • 直播伴侣的扬声器采集选择主程序正在使用的输出设备，确认音量条跳动；如版本支持单独应用音频，选择主打印台而非小窗。对应采集原理见官方音频说明
  • 需要口播时再开启麦克风；相同声音只采集一次。将直播间登录窗口静音，避免把自己直播的延迟声音再次播出去
4

自己开播，再连接自己的直播间

  • 画面与声音预览确认后，由你在直播伴侣中点击开始直播。相关界面见官方开播指南
  • 回到打印台右侧「直播连接」，填写自己的数字房间号或完整 live.douyin.com 直播链接，点击「打开直播间窗口」
  • 在本程序打开的登录窗口中扫码/完成验证，确认已进入自己的直播间，再点击打印台的「开始抓取」；直播伴侣和这里的登录状态相互独立
  • 等待直播数据桥已连接。之后观众的新互动按打印规则进入队列，连接前的历史弹幕不会补打印
5

核对互动和观众端效果

  • 收到一条新评论后，查看打印台计数、队列和打印记录，再核对直播伴侣预览及手机观众端的画面、声音
  • 默认评论和礼物会打印，进场 / 点赞 / 关注打印默认关闭；需要时在「打印规则」中打开，并调整每次张数、大小和语音
  • 直播时「无互动时补测试头像」默认关闭，可单独开启并设置等待时间；它与断开数据桥时的自动演示是两项设置
  • 结束时先在直播伴侣停止直播，再关闭打印台。关闭打印台会清理它启动的小窗、登录窗口和数据桥，不会替你停止直播伴侣推流

常用操作 TIPS

视角与镜头

画面里按住拖动即可转动视角；「＋保存当前视角」最多存 10 个命名镜头；随手拖动的机位会自动记忆，刷新不丢；「初始视角」一键回位。

画质与状态牌

高级画质设置提供低 / 标准 / 高 / 超高预设、抗锯齿、目标帧率和流畅优先。输出分辨率单独设置，内部渲染倍率不代表输出尺寸成倍增加；「状态牌」可显示/隐藏打印状态。

暂停 / 跳过 / 速度

「暂停打印」同时冻结打印和流水线；「跳过当前」只丢弃正在打印的这件；演示速度 1× / 4× / 12× 可加速验收。

切换直播间

在「直播连接」填新房间号，重新打开对应直播间窗口、确认登录后开始抓取，数据桥会跟随房间设置。

批量导入头像

规则演示台里「批量导入头像」可选本地图片，替换演示头像池，仅本机使用不上传。

礼物优先插队

开启后会立即切换到礼物打印，未完成的普通任务保留到礼物之后重新打印；礼物之间按收到的先后顺序处理。关闭此选项则按普通队列顺序打印。

常见问题 FAQ

双击后窗口打不开？

先查看启动窗口的报错，确认已运行 setup.bat 安装依赖，并已安装 WebView2 Runtime。服务会自动尝试空闲端口；全部备用端口都被占用时，关闭旧的打印程序或本地服务后重试。不要直接双击 HTML 文件。

直播伴侣捕获黑屏 / 选到控制台？

先保持主窗口和小窗开启、不要最小化，在直播伴侣中重新选择「直播小窗 · Avatar Printer」，旧素材也要重新选窗口。仍黑屏时，可在打印台高级画质设置中点击「开启捕获兼容模式并重启」，之后重开小窗并重新采集；兼容模式会增加 CPU 开销，可降低画质与帧率。

小窗一直显示等待主窗口画面？

确认主打印台仍在运行且没有最小化。先关闭小窗再从主窗口点击「弹出画面」重开；不要从另一个端口或另一份项目打开小窗。

点「开始抓取」提示端口 8765 被占用？

有旧的数据桥还在运行。按提示关闭旧版 ServerGuard / BridgeGuard / 旧数据桥窗口，再重新开始抓取。

抓取状态一直是「等待直播动态」？

直播间窗口还没登录或没进入直播间。先在直播窗口完成登录并进入房间，再点开始抓取。

有些观众显示彩色首字而不是照片头像？

TA 的头像暂时没抓到（比如已滚出屏幕）。软件会自动多轮点击资料卡补取，观众多发几条评论通常就能抓到真实头像。

直播间没人发消息也在打印？

未连接数据桥时，自动演示按设置的间隔补位；直播连接后自动演示关闭。若仍补测试头像，检查「无互动时补测试头像」是否开启，以及数据桥是否已断开。

自己能听到，观众听不到声音？

直播小窗本身静音，声音在主打印台。先点「开启声音」，再确认直播伴侣扬声器采集的设备与主程序输出设备一致、采集未静音且音量条跳动。避免同一声音被系统采集、应用采集或声卡重复混入。

分数是真实的吗？

不是。评分为 60–95 的娱乐随机分，不同分数段对应不同打印材质（胡桃木/拉丝铝/石材/陶瓷等），仅作直播互动效果。

登录和账号操作

登录由你在本程序打开的抖音直播间窗口中完成，程序不代发弹幕、不点赞、不送礼。使用公开互动数据时请遵守平台规则；直播权限和账号状态以抖音显示为准。
